The collection of files here provide the scripts to run an optimization case, with further details found in the corresponding paper:
Guo, J., Roy, T., Govindarajan, N., Varley, J.B., Raisin, J., Lee, J., Jang, J., Lee, D.U., Jaramillo, T.F. and Lin, T.Y., 2025. Optimized tandem catalyst patterning for CO $ _2 $ reduction flow reactors. arXiv preprint arXiv:2511.07638.

------------NOTE: This branch is not actively maintained/updated.--------------------

Simulation cases in the corresponding paper were run using with the following software versions:

List of files provided:
 
1. This document (Notes.txt) giving an overview of what is in this branch and what files are included.

2. Optimization script file (OPT_script_with_documentation.py) with the optimization capability (to find the optimized section lengths given an initial pattern and number of sections). Strong regularization (smaller S sharpening parameter value) is used, and the following species are omitted from the electroneutral NP system to save on computational cost: H2, C2H4, C2H6O, CH4.
Comments are provided within the file.

The script is run using the following command on the command line:
python OPT_script_with_documentation.py <n_sections> <objective: current/FE> <V_final> <flow_rate> >> output_log_file.log

or, in parallel with p processors:
mpiexec -n p python OPT_script_with_documentation.py <n_sections> <objective: current/FE> <V_final> <flow_rate> >> output_log_file.log


3. An example list of lengths of sections for the optimized pattern (opt_length_list.txt) for N = 8 sections. The length values are taken from the results of the optimization script file; this file is then used as the input of the forward script.
